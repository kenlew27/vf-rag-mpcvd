S1 Implementation record
Table S1 records the model dependencies. Intent classification and synthesis use Claude Sonnet 4 (claude-sonnet-4-6, Anthropic); claim verification uses Claude Haiku 4.5 (claude-haiku-4-5-20251001, Anthropic). Intent classification uses a single constrained LLM call with 16 examples and 14 classification rules. Query types are canonically ordered. The structured-data lane has seven stages: (1) runtime schema loading; (2) constrained planning into one of four operations: rows, aggregate, cohort rows, or unsupported; (3) relational validation; (4) allowlisted entity resolution using Unicode NFKC normalisation; (5) parameterised SQL compilation; (6) BigQuery dry-run validation and cost estimation; and (7) execution into typed records. Cohort queries use common table expressions with row-number partitioning capped at 25 rows per group.
Table S1 System component configuration.
Dense retrieval uses voyage-4 embeddings in LanceDB. Reciprocal-rank fusion weights semantic and keyword results 0.7 and 0.3 with smoothing constant K = 60. A BAAI/bge-reranker-base cross-encoder reranks candidates. The relevance threshold is 0.01; over-fetch is three times the target. Parent expansion occurs when more than 50% of siblings hit or when at least two sibling chunks appear. Evidence identifiers use an EV- prefix, a source-type letter, and at least three digits. Claims are verified in batches of two. A schema failure triggers one batch recovery attempt before claims are evaluated individually.
Experiments were run on a Google Cloud e2-medium instance (2 vCPU, 4 GB RAM) running Python 3.12. No GPU was used. Pipeline latency was not a primary evaluation target; all reported metrics are correctness-based.
S2 Benchmark construction details
Intent queries span four task types and four source categories. Routing labels cover combinations of structured database (S), internal documents (D), and external literature (L). Each structured-retrieval item includes a natural-language question, the supervisor-decomposed query, reference SQL, and expected rows; evaluation checks SQL execution, columns, rows, and required values. Literature passages receive expert ratings of not relevant, relevant, or highly relevant; the 128-query synthetic set uses exact chunk-ID matching.
Claim-verification fixtures use four offline reason codes: scope_or_causal_overreach, source_denial_conflict, source_backed_statement, and cross_context_inference_unresolve. Evidence varies across short clean, medium clean, long clean, long noisy, and long noisy reordered conditions, and across database, document, and mixed sources. These reason codes support error analysis; Fig. 5 reports the authoritative gold-label slices and does not substitute a reason-code crosswalk.
The end-to-end scientist evaluation uses 50 questions from the standardised CVD diamond question set, spanning three complexity buckets: B1 (database lookup, 20 questions), B2 (database and literature synthesis, 24 questions), and R (research hypothesis generation, 6 questions). Pipeline outputs were generated using the default pipeline configuration. Two domain scientists scored each output independently using a single-page HTML grading workbench that presents the question, the full pipeline answer with all cited evidence (database records and literature passages), and three 5-point Likert rating scales. The rubric definitions are: Grounded (5 = every claim traceable to cited evidence, 1 = free-form generation), Correct (5 = factually accurate, 1 = contains errors), and Scientific Rigor (5 = calibrated and appropriately bounded, 1 = overconfident or unsupported claims). Each grader also provides optional free-text notes. Graders did not see each other's ratings; the order of questions was fixed.
S3 Illustrative residual failure modes
Three cases from the 100-fixture set illustrate proposition-level intervention. First, fixture V3B-B001 accurately cites 120 nm step heights, then invents a 6 ppm nitrogen condition, nearly five-fold area expansion, and lateral dimensions above 8 mm from a 3.5 × 3.5 mm² substrate. Evidence EV-L-003 contains no such expansion, so the extra propositions are unsupported. Second, a synthesis cites EV-S-001 but reports 99.0 μm h⁻¹ at 900 °C when the record contains a different growth-rate magnitude; the verifier marks the contradiction. Third, fixture V3B-B002 accurately reports transitions at 875 °C and 950 °C for 75–200 ppm nitrogen in one reactor, then generalises them to every reactor, sample, and condition; the verifier intervenes on the universal claim.
